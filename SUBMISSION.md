## Status

**Working end to end:**
- create, rename, edit, autosave, reopen and delete documents
- rich text: bold, italic, underline, strikethrough, H1–H3, both list types, quotes
- `.txt` / `.md` / `.docx` import into a new document
- sharing as owner, editor or viewer, with role changes and revoking
- separate "My documents" and "Shared with me" lists
- persistence
- conflict detection (409)
- Markdown export
- validation and error states
- version history with preview and restore (a restore can be undone)
- text alignment
- save-failure handling: stops on 404/403, retries network errors with backoff, no retry loops
- 8 API tests plus a 17-check E2E UI run

**Incomplete or simplified:**
- Auth is mocked: seeded users, no passwords.
- There's no real-time co-editing. Two people editing the same document at once get a "Reload" conflict prompt rather than merged changes.
- `.docx` import keeps structure and basic formatting (whatever `mammoth` maps); images and tables are dropped.

**With another 2–4 hours I'd build:**
1. Real-time co-editing with Yjs plus a small WebSocket server, along with presence avatars and cursors. This replaces the 409 prompt.
2. Real authentication (email magic link or OAuth) and inviting people who don't have an account yet.
3. Comments anchored to text ranges.
4. A side-by-side diff between two versions in the history panel.
